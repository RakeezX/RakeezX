## التطوير والنشر

الواجهة HTML وCSS وJavaScript ESM، وتُخدم أصولها كملفات ساكنة. يحتوي المشروع أيضًا أدوات Node/npm وVite وتوليد build metadata؛ وصف «لا Node ولا أدوات بناء» تاريخي. أمر البناء المسجل في `package.json`:

```sh
npm run build
```

استعمل الاعتماديات الموجودة وشغّل الفحص الذي يمسّه التغيير. وجود Vite لا يحدد وحده مجلد النشر: اتبع إعداد مزود المشروع الفعلي وتحقق من أصول النسخة التي يخدمها، ولا تفترض رفع `dist` أو نسخ مجلد عمل كامل. `buildSha` من نوع content ليس Git commit SHA.

ابدأ الأتمتة من `scripts/ops-supervisor-v4/start-ops.ps1` تحت حساب المستخدم الحالي؛ controller واحد يدير التنفيذ والتسليم. الحالة الأصلية في `artifacts/ops-supervisor-v4/queue`، والملخص الحي `ACTIVE_TASKS.json` في المجلد نفسه. لا تستنتج أن عملية حيّة تعني تقدم تذكرة أو نشرًا.

احفظ بيانات المعلمين والطلاب وتاريخها والعزل والمزامنة. لا مفاتيح سرية أو service-role في المتصفح، ولا تعديل بيانات حقيقية أو ترحيلات أو إرسال خارجي بلا التفويض المطابق. التفاصيل في مراجع المنتج أعلاه؛ تاريخ Git يحتفظ بالوصف القديم.
