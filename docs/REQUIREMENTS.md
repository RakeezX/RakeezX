# المتطلبات — RAKEEZ X

آخر تحديث: 2026-08-16 · مدمج من مراجعات المتطلبات السابقة، ومحدَّث بما نُفّذ فعلًا.

---

## السياق

معلّم **مهارات رقمية للمرحلة الابتدائية** (صفوف ٤–٦) في السعودية، يبني أداةً لنفسه.
حصتان أسبوعيًا لكل فصل. سنة دراسية بفصلين.

**الأولويات، بهذا الترتيب:** صحة النموذج · سلامة البيانات · العمل دون إنترنت ·
الترحيل الآمن · وضوح البنية.

---

## ما نُفّذ

| المجال | الحالة |
|---|---|
| السنة الدراسية والفصلان | ✅ كيانان مستقلان بتواريخ وترتيب وحالة |
| الشعب والإسناد التدريسي | ✅ مفصولان |
| الطالب هوية مستقلة + الانتساب | ✅ انتقال بين الشعب، وخروج من المدرسة، وعودة |
| السجل التاريخي للطالب | ✅ سجل انتساب كامل بتواريخه |
| الحصص | ✅ سبع حالات · حصتان في يوم واحد · وقت مطبوع في الحصة |
| الجدول الأسبوعي | ✅ خانات متكررة، وعدد الحصص مشتق منها |
| ملفات توقيت الحصص | ✅ أربعة ملفات قابلة للتعديل، مع استثناء لكل يوم |
| التقويم الدراسي | ✅ النموذج والإدخال اليدوي · الإجازة تُلغي الحصة تلقائيًا |
| المنهج (وحدات ودروس) | ✅ مفهرس بـ (مادة + صف + رقم الفصل) |
| ربط بند التقييم بالمنهج | ✅ في النموذج — بلا واجهة |
| الحضور | ✅ مرتبط بالحصة · الحصة غير المنفّذة لا تولّد غيابًا |
| الدرجات والبنود | ✅ بنود قابلة للتخصيص وبنود آلية |
| الرصد السريع | ✅ مشاركة وسلوك مع تراجع |
| التقارير | ✅ فصل · طالب · حضور · من يحتاج دعمًا · CSV · طباعة |
| القرعة والمجموعات ولوحة النتائج | ✅ |
| النسخ الاحتياطي | ✅ تصدير · دمج · استبدال · ترحيل النسخ القديمة |
| العمل دون إنترنت + PWA | ✅ مُختبر بإطفاء الخادم فعليًا |
| تعدد التبويبات | ✅ دمج حقلي بلا فقد |
| الأرشفة | ✅ `year.status` و `term.status` |

## ما هو مؤجّل عمدًا

| الميزة | لماذا التأجيل آمن |
|---|---|
| مولّد حصص الفصل الدراسي من الجدول | النموذج جاهز؛ يحتاج تواريخ الفصل الدراسي أولًا |
| استيراد تقويم وزارة التعليم آليًا | الجداول تستوعبه؛ الإدخال يدوي الآن |
| واجهة تحضير الدرس | حقول الحصة جاهزة (`lessonId`, `homework`, `covered`) |
| واجهة الملاحظات المؤرّخة | **قرار D-13 مفتوح** |
| واجهة الواجبات والتسليمات | **قرار D-12 مفتوح** |
| تقارير إتقان المفاهيم | الحقول موجودة، الواجهة مؤجلة |
| تقرير السنة الدراسية | منطقة معلَّمة في «التقارير» |
| شاشة الأرشيف وتصفّح السنوات | `status` يكفي؛ الشاشة عرض |
| التحميل الكسول للسنة النشطة | حتى يتراكم حجم يستدعيه |
| فهارس IndexedDB | الأداء الحالي يكفي |

## خارج النطاق تمامًا

تعدد المعلمين على نفس البيانات · تطبيق جوال أصلي (مُثبَّت أصلًا كـPWA) ·
التكامل مع نور أو مدرستي · بنك أسئلة · محتوى تفاعلي · إضافة متصفح · ذكاء اصطناعي ·
الانتقال إلى React أو أدوات بناء (لا سبب تقني — المعمارية صمدت تحت الاختبار).

## متطلبات مستقبلية مسجّلة

النموذج **يستوعبها بلا إعادة بناء**، وهذا مُختبر:

- جدول المعلّم الأسبوعي بواجهة كاملة
- تتبّع إنجاز المنهج مقابل الخطة الزمنية
- ملف الطالب الشامل عبر السنوات
- الشهادات وقوالب الطباعة المتقدمة
- تقارير السنة الدراسية الكاملة
