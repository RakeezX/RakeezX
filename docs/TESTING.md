# نتائج الاختبارات — MADAR Z

آخر تحديث: 2026-08-16 · مدمج من التدقيق الهندسي واختبار القبول واختبارات الموجة الأولى.

**قاعدة ثابتة في كل ما يلي:** لا يُعتبر الاختبار ناجحًا لأن الشاشة ظهرت — تُقاس
البيانات نفسها، ويُحسب المتوقع يدويًا من السجلات الخام ويُقارن بما يعرضه التطبيق.

---

## بيئة الاختبار

«الفصل التجريبي» — سنة ١٤٤٨-١٤٤٩، فصل دراسي أول، شعبة ٤/أ بـ**٢٥ طالبًا** بأسماء
من ٣ إلى ٦٢ حرفًا (الطول مقصود)، وشعبة ٤/ب، ودرجات وحضور ورصد.

## الاتساق

بعد كل جولات الاختبار، على ٣٥٠+ سجلًا:

```
اليتامى              : صفر عبر ٧ علاقات
الدرجات المكررة      : صفر
الحضور المكرر        : صفر
الحصص المكررة        : صفر
المعرّفات المكررة عالميًا : صفر
الدرجات خارج النطاق   : صفر
المعرّفات المشتقة      : سليمة ١٠٠٪
```

## التحقق الحسابي المستقل

حُسبت درجة طالب يدويًا من السجلات الخام، بلا استعمال دوال التطبيق:

```
البنود اليدوية : 31.5
المشاركة الآلية:  6.0
─────────────────────
المتوقع        : 37.5 / 50 = 75٪
التطبيق        : 37.5 / 50 = 75٪   ✅ مطابق
```

ومجموع الغياب في كشف الحضور = مجموع غياب الطلاب فرادى ✅

## ما لم يُختبر

**اختبار الجوال الحقيقي.** كل ما نُفّذ محاكاة مقاس ٣٧٥×٨١٢ مع لمس مُحاكى، وهي لا تكشف
سلوك سفاري iOS ولا لوحة المفاتيح ولا تدفّق التثبيت. قائمة الفحص:

- [ ] التركيز على حقل درجة في وضع الجدول — هل تقفز الصفحة؟ *(أُصلح نظريًا بـ ١٦px)*
- [ ] لوحة المفاتيح مفتوحة — هل تغطّي الشريط السفلي أو الزر العائم؟
- [ ] اسم طالب طويل جدًا — هل يكسر الصف؟
- [ ] «إضافة إلى الشاشة الرئيسية» ثم الفتح من الأيقونة
- [ ] وضع الطيران ثم فتح التطبيق
- [ ] رصد حضور، إغلاق التطبيق تمامًا، إعادة فتحه بعد ساعة
- [ ] **iOS:** تركه أسبوعًا دون فتح ثم فتحه — هل البيانات موجودة؟
