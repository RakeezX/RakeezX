## الهدف القابل للقياس
إنشاء خط حماية قابل لإعادة التشغيل يتحقق من عدم وجود مخالفات WCAG عالية الأهمية، أو تمرير أفقي في الواجهات، أو إخفاق تحميل مسارات المعلم المتاحة بأمان. معيار القبول: صفر مخالفات serious/critical، وصفر تجاوز عرض، وصفر فشل تحميل في 30 مسار Demo.

## نطاق المسح
- 39 مسارًا معرفًا في router.js.
- 30 مسارًا آمنًا للفحص بالبيانات الاصطناعية (ثلاثة أوضاع: 320px فاتح، 390px داكن، 1280px فاتح).
- فحص axe WCAG على أول وضعين؛ قياس تجاوز العرض في الأوضاع الثلاثة؛ فحص DOM والسجلات وخطوط التفاعل.
- لا بيانات أو حسابات معلمين حقيقية، ولا تشغيل خدمة خارجية؛ Service Workers والطلبات الخارجية محجوبة.

شمل الفحص: الرئيسية، الفصول، مساحة الفصل وقواعده، كشف الطلاب، الحضور، الرصد السريع، الدرجات، بنود التقييم، القرعة، المجموعات، اللوحة، الحصص وتقارير الفصل، سجل الطالب، الجدول وأوقاته، المناهج، مركز التقارير والشهادات وكشوف الدرجات والمتابعة والتنفيذ، الأرشيف العام والسابقين، التقويم، الإعدادات والنسخ الاحتياطي والدعم.

## حدود الإثبات والتوافق
- هذا مسح للمسارات في Demo، وليس اختبارًا لكل أزرارها أو قواعد الدرجات أو تكامل الخدمات.
- لا ادعاء بتغطية بيانات الحساب الرئيسي أو السحابة أو Sync أو المنصة أو العمل دون إنترنت على الهواتف الفعلية.
- WebKit وFirefox: اختبارات صفحات مركزة نجحت في الجولات السابقة، لكن **الماسح الشامل لثلاثين مسارًا لم يحصل على حالة Demo مستقرة لبدء القراءة**؛ ولذلك لم يعد نجاحهما الشامل مثبتًا. توجد آثار فشل وتحقق منفصل محلي محفوظة، ولا يُغيّر فشل الاختبار إلى PASS.
- يلزم فحص Safari وAndroid/iOS فعلية عند اعتماد تغييرات مؤثرة باللمس أو لوحة المفاتيح.

## نتيجة التحقق اللاحق

## خلل إضافي اكتشفه فحص Cloudflare الحقيقي
بعد نجاح اختبار 30 مسارًا محليًا، فشل فتح تقرير التنفيذ على Preview المنشور. كشف سجل المتصفح أن صفحة التقرير تستورد CSS مباشرة بوصفه JavaScript module؛ يستجيب الخادم بملف text/css ويطبّق المتصفح فحص MIME الصارم، فتبقى شاشة التقرير السابقة ظاهرة رغم تغيّر العنوان. هذا الاستيراد موجود أيضًا في مصدر main وقت التدقيق، وبالتالي لم يكن ناتجًا عن تغييرات UX الجديدة وحدها.

**الإصلاح في المرشح:** إزالة استيراد CSS المباشر من execution-report.js، وتحميل filters.css بواسطة link rel=stylesheet في beforeRender قبل العرض، بنفس آلية صفحات التقارير والدرجات الأخرى. أُضيف اختبار Node باسم ux-native-esm-contract.test.mjs يمنع رجوع استيراد CSS المباشر في ملفات JavaScript المصدر. هذا خطأ كشفته بيئة النشر الحقيقية ولم يكن فحص Vite المحلي وحده كافيًا لاكتشافه.

لا يُعتبر الإصلاح منشورًا وناجحًا حتى يجتاز فتح التقرير في رابط Preview الجديد وفحص التركيز وWCAG عليه. لا دمج أو نشر Production تلقائيًا.
