# RAKEEZ X — Visual Direction & Design System

## Core Identity
**رَكيز X | RAKEEZ X**
*الركيزة الرقمية للمعلم*
*Built for Teachers. Powered by Intelligence.*

## Design Philosophy
Premium, modern Saudi education SaaS product. Clean white/light surfaces, strong Arabic typography, large comfortable cards, high readability.

## Typography
- **Primary Font**: IBM Plex Sans Arabic (or similar modern Arabic web font like 'Tajawal' or 'Cairo' as fallback)
- **Base Size**: 16px
- **Hierarchy**:
  - Headings (h1-h6): Bold, high contrast (Navy)
  - Body: Regular, medium contrast
  - Meta/Subtext: Smaller, low contrast

## Color Palette

### Primary / Accent
- **Emerald Green (Trust/Education)**: `#18A878` (Primary brand color, buttons, active states)
- **Green Hover**: `#148f66`
- **Green Subtle**: `#e8f6f1`

### X-Premium / AI
- **X-Purple (AI/Smart Features)**: `#7857E8` (Used exclusively for smart actions, AI generators, premium insights)
- **Purple Hover**: `#6549c4`
- **Purple Subtle**: `#f2effc`

### Typography & Neutrals
- **Navy (Headings/Strong Text)**: `#15253D`
- **Base Text**: `#334155`
- **Muted Text (t-3)**: `#64748b`
- **Borders/Dividers**: `#e2e8f0`
- **Background/Surface**: `#f8fafc`
- **Card Surface**: `#ffffff`

### Semantic Colors
- **Danger/Error**: `#ef4444`
- **Warning**: `#f59e0b`
- **Success**: `#10b981`

## Surfaces & Spacing
- **Cards**: Pure white (`#ffffff`), subtle shadow (`box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.05)`), rounded corners (`border-radius: 12px`), border (`1px solid #e2e8f0`).
- **Spacing Scale**:
  - `sp-1`: 4px
  - `sp-2`: 8px
  - `sp-3`: 12px
  - `sp-4`: 16px
  - `sp-5`: 24px
  - `sp-6`: 32px

## Interactive Elements
- **Buttons**: Fully rounded or softly rounded (e.g., 8px). Smooth transitions (`transition: all 0.2s ease`). No heavy outlines unless focused.
- **Inputs**: Generous padding, clean borders, clear focus rings using the Primary Emerald color.

## Accessibility
- Minimum contrast ratio of 4.5:1 for normal text.
- Focus states must be visible.
- Touch targets at least 44x44px on mobile devices.
