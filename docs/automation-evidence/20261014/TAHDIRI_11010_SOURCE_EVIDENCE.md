## Rakeez recommendations — not deployed features
Build one compact weekly-preparation flow over existing identities: week+saveddefaults→exceptions review→teacher-confirmed provider save, with durable result per lesson/version, then link actual tasks and optional parent communication. Keep timetable, preparation and provider acceptance distinct internally without burdening UI with many controls. Reuse actual lesson/session status entered by teacher rather than demanding a second identical conducted-confirmation action. A specific strategy-use or claimed learning impact still needs its own actual supporting record.
Support stages/subjects via versioned grade/subject/curriculum/year/region/term/lesson identities and coverage records, not a different script per subject or unverified all-content claim. Sources: teacher-authorized platform tree, teacher-supplied/allowed distributions, our original/licensed content, and grounded optional generation; do not hotlink a competitor's private catalogue into Product without agreement.
Annual portfolio: reuse teacher/school profile, teaching assignments, recorded sessions/attendance/assessment and report snapshots; later add actual accepted prep/contact events. Manual certificates/photos/reflections remain teacher-supplied. Per-year filtering, source/version dedup and default student-data redaction. No invented courses/activities/strategy use or counting repeated exports as multiple achievements.
Prefer extension-bundled reviewed executable code with separately versioned data; don't blindly copy remote-newFunction updater. GoogleMV3 documentation is a design consideration, not an asserted adjudication of this particular store listing.
