2. من صفحة إضافات Chrome فعّل وضع المطوّر واختر «تحميل إضافة غير مضغوطة»، ثم اختر المجلد الذي يحتوي manifest.json. تحقق من الإصدار 0.5.0؛ عطّل النسخ التجريبية الأخرى عند الاستخدام. لا يلزم معرّف ثابت للإضافة.
