# تجربة N36 الاختيارية بعد النشر المتحقق منه — 0.5.5

هذه تعليمات تجربة لاحقة للمعلم، وليست إثبات نشر أو نجاح على مدرستي. لم يدخل العامل حسابًا رسميًا أو يقرأ أو يكتب بيانات طلاب حقيقية. يبقى N36 مفتوحًا حتى قبول PO للتجربة الفعلية.

1. بعد أن يتحقق الناشر المستقل من النسخة المنشورة وبصمات الحزمة، يحدّث المشغّل المعتمد المجلد الثابت `C:\Users\Abody\Projects\RakeezX\artifacts\private-tools\n36-current\runtime`. تحتفظ الحزم السابقة بمكانها. يضغط المعلم Reload للإضافة نفسها؛ لا تثبيت نسختين ولا تحكم آلي في متصفحه الشخصي.
2. يفتح المعلم مدرستي بنفسه ويبدأ الإضافة طوعًا من الصفحة المصرّح بها. لا بيانات دخول أو ملفات تعريف ارتباط أو قراءة إطارات مخفية مطلوبة.
3. يقرأ حالة التغطية والأعداد. «استيراد المتاح فقط» يعني أن أسماء أخرى قد تكون مفقودة؛ لا يعني كشفًا مكتملًا ولا عددًا إجماليًا مقدّرًا. الصف غير الصالح أو المجهول لا يُخمن.
4. يختار فصل المصدر ويراجع أسماء الدفعة الظاهرة. للكشف الناقص يؤكد فهم النقص أولًا، ثم مراجعة الدفعة. يمكن أن يتجاوز الحساب أو الفصل 300 طالب؛ الحد يخص النقل الواحد فقط، وليس إجمالي الطلاب.
5. داخل حسابه في ركيز يطابق الفصل بفصل مملوك له، ويختار التدريس والسياق الصحيحين، ثم يعاين الأسماء الجديدة والموجودة ويؤكد الإضافة بنفسه. لا كتابة قبل التأكيد.
6. يعود إلى الإضافة لقراءة الإيصال. لا تفتح الدفعة أو النافذة التالية تلقائيًا؛ يراجع ويؤكد كل دفعة، ثم يختار «متابعة صريحة» عند تسوية الدفعات الحالية. الإيصال يثبت نتيجة محلية؛ لا يثبت مزامنة الخادم.
7. إن فشلت العملية أو فُقد الإيصال فلا يُفترض الحفظ ولا تُتجاوز الأسماء المعلقة. يختار إعادة مراجعة الدفعة نفسها؛ يعيد ركيز فحص الموجود لمنع إضافته مرة أخرى. تغيير الحساب أو القفل أو السياق يبطل المراجعة.
8. تنتهي المعاينة بعد خمس دقائق وتُمسح الأسماء المؤقتة. يمكن البدء طوعًا مجددًا مع فحص التكرارات. لا تطلب هذه التجربة الاحتفاظ بالأسماء في تخزين دائم أو تجاوز صفحة منعها المصدر.

للملاحظات يكفي ذكر النسخة، والأعداد، وحالة التغطية ورمز السبب في التشخيص المحدود. لا ترسل أسماء الطلاب أو روابط المدرسة أو بيانات الدخول. نجاح الفحوص الاصطناعية لا يُسجل نجاحًا على المصدر الرسمي.
