## العائق المحدد وشرط الاستئناف

جرى فحص `--help` للأدوات المثبتة فقط: Supabase CLI `2.120.0` يتيح SQL وإدارة أسرار Edge، وWrangler `4.148.0` يتيح أوامر أسرار Worker. نجحت قراءة أسماء أسرار المشروع دون عرض القيم أو بصماتها؛ لا توجد أسماء `N44_*`. فحص الحضور فقط أكد غياب `N44_DATABASE_URL` و`N44_CRYPTO_JSON` من بيئة هذه العملية. لم تُقرأ ملفات أسرار أو ذاكرة ملفات تسجيل الدخول.

المفقود هو **قناة إنشاء/إلغاء LOGIN محدود لـ`n44_backend` وتسليم اتصاله الآمن إلى مخزن الخادم**. الأدوات المتصلة وأوامر CLI المفحوصة لا تعرض حقلًا مخصصًا وآمنًا لكلمة مرور هذا الدور؛ قبول SQL أو ملف SQL لا يحقق شرط البطاقة. وجود مخزن أسرار Edge لا ينشئ حساب قاعدة البيانات. توثّق Supabase [أسرار Edge](https://supabase.com/docs/reference/cli/supabase-secrets) و[أدوار Postgres](https://supabase.com/docs/guides/database/postgres/roles) كعمليتين منفصلتين.

يُستأنف التشغيل المحفوظ عندما تتوفر هذه القناة المصرّح بها لحساب `NOINHERIT/NOBYPASSRLS`، عضو `n44_backend` فقط، بلا منح مباشرة على Auth أو البيانات الأساسية، وبلا كلمات مرور في SQL أو الوسائط أو الأدلة أو السجلات. بعد ذلك تُستكمل فقط شروط freshness/preflight والتعطيل/readback الدقيقة قبل أي تطبيق؛ لا إعادة لدورات OAuth أو الاختبارات المحلية الناجحة لمجرد الانتظار.
