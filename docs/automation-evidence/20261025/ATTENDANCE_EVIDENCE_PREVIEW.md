# RAKEEZ — شاهد متابعة الحضور (Preview)

- **طلب المستخدم:** بدء أول إضافة من ملف الإنجاز والشواهد؛ مراجعتها على Preview قبل توسيعها أو نشرها.
- **الرابط داخل ركيز:** `#/reports/attendance-evidence` من صفحة التقارير.
- **المصدر:** `store.executionReport` الذي يستخدمه تقرير «الحصص والحضور» الحالي، وفقط الصفوف التي تملك عددًا موجبًا من سجلات حضور الطلاب المرتبطة بالحصص المؤرخة.
- **فهم النسب:** تغطية الرصد هي نسبة الحقول المرصودة إلى المتوقع **داخل الحصص ذات الرصد فقط**، وليست نسبة حضور الطلاب ولا تقييمًا لأداء المعلم.
- **حالات الاستبعاد:** الحصص الملغاة أو المستبعدة، الحصص التي لا يوجد لها رصد، التكرارات والأعداد غير المتسقة. يظهر تنبيه بالحالات المستبعدة.
- **بيانات الوثيقة:** الفصل والمادة والنطاق الزمني، التاريخ، شعار الوزارة، المدرسة، اسم المعلم وتوقيعه، أرقام الرصد وحالات اكتماله، وبيان واضح بمصدر البيانات وحدوده. لا توجد أسماء طلاب أو سجلات خاصة داخل الملف.
- **التصدير:** معاينة داخل الصفحة + نافذة الطباعة / «حفظ بتنسيق PDF» باستخدام ترويسة ومحرك طباعة التقارير الموجودين. لا توجد وظيفة حفظ تلقائي في ملف الإنجاز ولا كتابة حسابية جديدة.
- **الاختبارات:** 6 حالات إسقاط مستقلة، وفحص graph للعمل دون اتصال، و2 Playwright Demo واجهة/طباعة تشمل شرط صفحة A4 واحدة لشاهد حصتين، والتصفية بلا نتائج، ومطابقة السجلات دون تعديلات.
- **النشر:** Preview فقط. هذا العمل ليس قبولًا تلقائيًا للشواهد الأخرى ولا لإضافة ملف إنجاز كامل.
