# F09 — نسخة حماية محمولة لشواهد ملف الإنجاز وصورها (Preview)

تاريخ التنفيذ: 26 أكتوبر 2026. النطاق: الفرع المعزول F09 وDemo وPreview، دون نشر Product أو تعديل مخطط قاعدة ركيز أو مزامنتها أو Auth/RLS أو أي قاعدة معلمين حية.

## الهدف المباشر
تخفيف خطر فقد مسودة ملف الإنجاز بسبب تنظيف بيانات المتصفح أو تعطل الجهاز. في شاشة F09 يستطيع المعلم تنزيل نسخة **خاصة بملف الإنجاز لهذا الحساب وهذا العام** تحوي الشواهد والنصوص والتخصيصات والصور معًا، ثم اختيارها للاستعادة بعد فحصها وإظهار ملخصها.

**هذه أداة حماية مرحلية مستقلة.** لا تدخل الآن في نسخة N71 الموحدة لبيانات ركيز، ولا تعني أن النسخ الاحتياطي السحابي أو المزامنة بين الأجهزة جاهزان. لا يُقال إن رابط Preview ذي بصمة مختلفة سيحتفظ بـIndexedDB من رابط سابق؛ يحتاج المستخدم إلى تنزيل النسخة ثم استعادتها يدويًا، أو البقاء على اسم مضيف الفرع الثابت.

## عقد النسخة المحمولة
- نوع النسخة `rakeezx-f09-local-archive` وإصدارها `1`. تنسيق JSON نصي؛ يتضمن `scope` للحساب والسنة وقاعدة المستخدم، و`payload` للشواهد، و`attachments` لملفات الصور الأصلية `Blob` بعد ترميز base64.
- سلامة النسخة: SHA-256 للحمولة الإجمالية وفق JSON مرتب المفاتيح، وبصمة منفصلة SHA-256 لكل صورة مع حجمها ونوعها. يمنع ظهور إقرار استعادة لصورة ناقصة أو ملف تالف. هذه **سلامة محتوى لا توقيع ثقة أو تشفير**؛ يمكن لأي شخص يملك الملف قراءة الصور، لذلك لا يشارك علنًا.
- حدود الإصدار المرحلي: ملف لا يتجاوز 105MiB، وصور لا تتجاوز 100MiB و180 صورة، مع حد صورة 6MiB وأنواع PNG/JPEG/WebP، قبل استخدام ضغط/ZIP أو رفع متدرج آمن في مرحلة مستقبلية.
- المعلم يختار ملفًا، فيظهر عدد الشواهد الشخصية والصور، وتوضيح أن استعادته **ستستبدل مسودة هذا العام على هذا الجهاز**. لا تُنفذ الكتابة بمجرد اختيار الملف، بل بعد الضغط الصريح على «اعتماد الاستعادة المحلية».
- تحقّق النطاق يرفض حسابًا أو عامًا آخر. حماية Revision من نسخة قديمة تمنع الكتابة فوق تعديل أحدث في تبويب آخر أو بعد فتح معاينة الاستعادة، وتتولى معاملة IndexedDB ذرّية استبدال المستند والصور وتنظيف الصورة التي لم تعد ضمن المستند.
- تُفحص النسخة المستعادة من القاعدة مرة ثانية قبل إعلان النجاح، ويُعاد تكوين object URLs للصور. لا يُغيّر التصدير أو الاستيراد أي سجل درجات/طالب/فصل أو قيمة من `Product db`.
- لا ترسل النسخة إلى خادم ولا Supabase. حفظ الملف متروك للمستخدم داخل الجهاز؛ إلغاء اختيار الاستعادة لا يكتب شيئًا.

## علاقة هذه الخطوة بنظام N71
`src/lib/export.js` يحتفظ بإصدار النسخة الموحدة `BACKUP_VERSION=5` وبصمة حمولة وفق الحقول والجداول المعتمدة؛ `src/lib/backup-v2.js` يتولى تخطيط الاستعادة السحابية والمقارنة مع سجلات المالك والتاريخ والدرجات والحذف. وF09 يعمل في IndexedDB منفصل، فلا تظهر صور الشواهد في `db.STORES` أو `PORTABLE_CLOUD_RESTORE_STORES` بعد.

**شرط الانتقال إلى نسخة ركيز الواحدة:**
1. اعتماد عقد مستندات ملف الإنجاز ومرجع مرفقاتها في مسار sync/backup بنسخة بروتوكول جديدة متوافقة رجعيًا، لا إدخال حقول اعتباطية تتجاهلها الاستعادة.
2. إنشاء مكان حفظ خاص للصور مع RLS لكل مالك وعام ومستند، وإثبات أن نزاع تغييرات الهاتف والكمبيوتر أو حذف شاهد لا يعيد صورة أو سجلًا محذوفًا.
3. حفظ واستعادة فعلية عبر جهازين/حسابين اختباريين مع تغطية صور ومعايير مختلفة، ودليل أن N71 يسترجع **الصورة نفسها** وليس رابطًا منتهيًا أو بيانات وصفية فقط.
4. توصيل F09 بنسخة ركيز الموحدة **فقط بعد** قبول العقد والفحوص وحراسة Product؛ لا يطلب المعلم نسختين في الإصدار الإنتاجي النهائي.

## التحقق في هذه الجولة
- اختبارات الوحدة للأرشيف تختبر التصدير والاستيراد والتطابق النصي والـBlobs والبصمات، رفض حساب/سنة أخرى، ملف فاسد وإصدار غير متوافق، ووثيقة صالحة فارغة.
- Playwright على Demo اختبر تنزيل ملف فعلي ثم تعديل الشاهد ثم استعادة النسخة السابقة بعد التأكيد، الحفاظ على الصور بعد Reload، رفض نسخة حساب آخر وملف مُعدل، وإلغاء عملية الاستعادة دون الكتابة.
- اختبار تعارض يسترجع نسخة قديمة بعد تعديل محلي أحدث: **يرفض الاستبدال** ويبقى العنوان الجديد بعد Reload.
- اختبار متصفحين تجريبيين مستقلين على العام نفسه: نقل الملف يدويًا بينهما بنجاح دون الاحتياج إلى LocalStorage أو الصور من المتصفح الأول.
- نجاح الاختبار المحلي لا يثبت نشر Cloudflare؛ يلزم اختبار HTTPS المنشور ومطابقة بصمات الكود/المرفقات مع SHA المرشح قبل الإعلان.

## الأمان وحدود الاستخدام
لا استعمال لصور أو بيانات طلاب حقيقيين في الاختبارات. كل الأصول المستخدمة صور PNG صناعية. الملف JSON قابل للقراءة ويشمل الشواهد وصورها كما أدخلها صاحب الحساب، فلا يُرفع إلى محادثة أو رابط مشاركة عام. ميزات «مشاركة الرابط» و«QR» تبقى غير مفعلة حتى وجود خدمة Snapshot منشورة آمنة وقابلة للإلغاء.
