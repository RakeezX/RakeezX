Pinned successor: `d2a0c7c0930ecf71545c59150bae5b36fdd7ab3eb61c148317faf19ea4006c9c`. Prior native66: `f14daf224dc27b1163d43ce39ada2fdf596acd3abb4af30579404ad4f5de6390`. No migration, carrier upload or real-account operation is implemented.

`original-custodian.mjs` is an explicit-entry adapter, not a dispatcher. It runs only from the original N88 custody root, with the current canonical task/run/session, exact committed candidate and ownership-verified integration/live-mutation leases. It reuses the original protected owner marker, read-only isolation verification, CurrentUser DPAPI and installed supported CLI channels. It never alters ACLs or historical markers. Provider output/errors remain captured and only finite error categories leave the process.

Before any provider/private-state access, the adapter requires an actual committed `shared-phase-binding.json` in this directory. That file must bind this task and the fixed baseline digest to exact producer certificate revision/path/SHA256, source ancestor and original run. It is deliberately absent until genuine public evidence can populate it. No placeholder or synthetic fixture is a valid binding.

`committed-phase.mjs` binds public N44 bytes and their actual operation/readback/release receipts, with the original task/session/run and source ancestry. It accepts an unchanged committed ancestor artifact while unrelated commits continue. The configuration phase itself must be completed, cleaned and released; the whole worker need not finish. The prepared strict decoder requires explicit phase completion, keyset/aggregates, per-key prior/current digests and acknowledged readback/release references. If the producer uses a different genuine public schema, review and map its exact fields without weakening these facts before creating the binding. An expected-current-map certificate alone is insufficient.

The original non-pin baseline and keyset remain fixed. Metadata must reverse only individually proved named N44 changes to exactly that baseline. The current N88 source pin must match the finite expected prior/successor. Any keyset mismatch, unknown change, stale attested current aggregate or missing historical digest blocks the first provider action or the subsequent pin step. The shared leases cover the full metadata/native/upload/pin/readback sequence and must be released by the invoking worker's finally; they are never held while awaiting producer evidence.

The activation path reserves fixed task-bound upload and pin markers exclusively before their respective invocations, appends the original protected history, and never resets earlier source/migration records. Unknown acknowledgement stops without replay; `reconcile` is read-only and cannot complete another pin or clear a marker. Downloads verify exact native bytes and import map; configuration is compared before/after. The existing exact78/old76/history proof is immutable and reused. Only after a real PASS receipt may `integrate.mjs` copy the exact successor into the local bundle/manifest for the sole publisher. No public frontend change is invented.

Affected local tests are `transition-guards.mjs`, `activation-transition.mjs` and `committed-phase.mjs` under `tests/n88-denied-read-activation-20261023/`. They use fabricated descriptors/provider ports or a disposable public Git fixture; they do not certify service activation or user acceptance. Original PG17/session/grade/privacy/COMMIT and signed carrier/client evidence remains reused unchanged. Actual existing-account login/read/return remains NOT_RUN until coordinated after verified activation.
